# Lista de Compras (Shopping Web)

Aplicação web minimalista para gerenciamento de lista de compras, desenvolvida com React, TypeScript, Vite e Tailwind CSS.

## Requisitos

- Node.js 18+

## Como executar localmente

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
3. Para gerar a versão de produção:
   ```bash
   npm run build
   ```
